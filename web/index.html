ℹ About

System Architecture

🧠

Inference Engine

Uses forward chaining to derive BMI category and age group from inputs, then backward chaining to query applicable recommendation rules.

📖

Knowledge Base

28 Prolog rules (facts + rules) encoded from WHO Physical Activity Guidelines 2020 and Dietary Guidelines for Sri Lankans (SLNS).

💻

Implementation

Built in SWI-Prolog with an HTTP server exposing a REST API. The UI communicates with the Prolog engine via JSON.

🔍

Explanation Facility

Every recommendation displays its rule ID, source document, and reasoning trace — showing exactly how the conclusion was reached.
